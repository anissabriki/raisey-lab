# Raisey Lab — website

Static site. Open through any local server (`python3 -m http.server 8940`), then `http://localhost:8940/index.html`.

| File | Role |
|---|---|
| `index.html` | English site (source of truth) |
| `fr/index.html` | French site — **generated**: `python3 build_fr.py` |
| `privacy.html`, `fr/confidentialite.html` | Privacy Policy (+ mentions légales) — **generated**: `python3 build_legal.py` |
| `site.config.json` | PUBLIC settings: legal entity, address, contact email, siteUrl, basePath, customDomain, formEndpoint. No secrets. |
| `build_site.py`, `.github/workflows/deploy.yml`, `DEPLOY.md` | GitHub Pages build (`dist/`), CI workflow, deployment guide |
| `404.html` | Not-found page (generated by `build_legal.py`) |
| `_locked/` | Approved, locked services section: `python3 _locked/verify.py` |
| `fonts/`, `images/` | Self-hosted fonts; founder portrait (replace with a real photo) |

Production: see **DEPLOY.md** (GitHub Pages, launch checklist). `python3 build_site.py` builds `dist/`; `--production` enforces the launch gates.


## Presence Scan (copy, scoring, results email)
| File | Role |
|---|---|
| `scan_copy.json` | Single source for the interpretations, objective lines, nuance sentences and email copy (EN + FR). Edit here, then run `python3 build_fr.py`. |
| `scan_scoring.mjs` | Single source for the scoring (9 scored questions -> 6 dimensions). Inlined into the page and imported by the email renderer. |
| `email/render.mjs` | Renders the results email (HTML + text) from structured scores only. `node email/preview.mjs` writes previews; `node email/check.mjs` guards the agreed rules. |
